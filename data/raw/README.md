# Raw data

This directory holds the **raw, unmodified** files downloaded from the public sources
listed below. Nothing here is committed to the repository; `scripts/prepare_data.sh`
reads these files and writes the processed splits to `data/processed/`.

## Sources

| Dataset | File to place here | Source |
| --- | --- | --- |
| Amazon-Beauty | `ratings_Beauty.csv` | Amazon Review 2018 (ratings only) |
| Amazon-Sports | `ratings_Sports_and_Outdoors.csv` | Amazon Review 2018 (ratings only) |
| Amazon-Toys | `ratings_Toys_and_Games.csv` | Amazon Review 2018 (ratings only) |
| Amazon-CDs | `ratings_CDs_and_Vinyl.csv` | Amazon Review 2018 (ratings only) |
| ML-1M | `ml-1m/ratings.dat` | MovieLens 1M |

* Amazon 2018: <https://jmcauley.ucsd.edu/data/amazon/>
* MovieLens 1M: <https://grouplens.org/datasets/movielens/1m/>

The Amazon files are headerless CSV with columns `user,item,rating,timestamp`;
`ml-1m/ratings.dat` uses the `UserID::MovieID::Rating::Timestamp` delimiter.

## Synthetic dataset

`SyntheticHard` needs no download — it is generated by
`src/data/synthetic.py` (see `scripts/prepare_data.sh`).
